# @linky-fit/onchain-transfer guides

How to use Linky's on-chain transfer domain library. These are guides, not an API reference: the exported types are the reference, and the [package README](../README.md) holds the design rules.

- [Protocol](./protocol.md) — who sends what when, the operator's statuses, the phases Linky shows, idempotency and trust
- [Config](./config.md) — the operator's on-chain config, the service fee and the transfer amounts
- [Bitcoin](./bitcoin.md) — deposit addresses, address validation, payment URIs, explorer links, the Esplora client and deposit status

The stored rows are described in linksync's [repositories guide](../../linksync/docs/repositories.md#on-chain-transfers).
