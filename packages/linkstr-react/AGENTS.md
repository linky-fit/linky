# @linky-fit/linkstr-react

This package is documented together with `@linky-fit/linkstr`: `../linkstr/docs/react.md` is the usage guide (config, runtime, the atom table, inbox/outbox/profile-watch hooks), and the vertical guides in `../linkstr/docs/` name the fn atom for each direct operation. Changing an exported atom, hook or testing helper is done only when those guides are updated in the same commit; the rules and the vertical checklist are in `../linkstr/AGENTS.md`.
