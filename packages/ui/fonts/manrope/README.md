# Manrope

Unmodified Latin and Latin Extended WOFF2 subsets, normal weights 400, 600 and 700, from `@fontsource/manrope@5.3.0`:
https://registry.npmjs.org/@fontsource/manrope/-/manrope-5.3.0.tgz

Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope), SIL Open Font License 1.1. The license is `OFL.txt` beside the fonts, and each app that serves them also publishes it at `public/licenses/Manrope-OFL.txt`; keep all copies when updating the font. `manrope.css` keeps the upstream Unicode ranges and references only these files.
